{%- comment -%} The masthead section a post ran under, for the index, the hubs and the archive datelines. `edition:` front matter wins; otherwise it is derived from the title, so the daily Hedgers' Ledger bot needs no change to be labelled correctly. Everything that is not a Ledger release is a Weekly Tape note — the two named editions in about.html. With `key=true` the SAME rule renders a machine key instead of the display name. Callers that COMPARE editions must use the key: the display name carries an HTML entity (’), and no caller should have to spell that to match on it. The key is total by construction — anything that is not a Ledger is `tape` — so the two hubs always partition the run and no post can fall out of both.
